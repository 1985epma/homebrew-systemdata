# 1985epma/systemdata

Tap do Homebrew para o [EPMA System Data](https://github.com/1985epma/epma-system-data), app nativo para medir e limpar os Dados do Sistema (System Data) do macOS.

```bash
brew tap 1985epma/systemdata
```

```bash
brew install epma-system-data
```

```bash
epma-system-data
```

Relatório no terminal, sem abrir a janela: `epma-system-data --scan`.

Só macOS. A fórmula compila a partir do código-fonte (Rust).
